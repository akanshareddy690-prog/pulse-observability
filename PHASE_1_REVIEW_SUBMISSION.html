1. Problem Understanding & The Core Privacy Challenge

Modern enterprise IT systems span distributed microservices, multi-region cloud infrastructures, and edge networks. Traditional observability tools ship raw syslog streams, payload records, and application logs to central cloud vendors. In production, this introduces catastrophic compliance and security violations:

  • Data Exposure Risk: Shipping raw logs exposes unhashed passwords, AWS tokens (AKIA...), internal hostnames, and customer PII across the network perimeter.
  • Compliance Violations: Transferring unredacted records outside the customer region violates jurisdictional mandates (e.g., GDPR, HIPAA, RBI local residency).
  • Alert Fatigue: Static thresholds spam engineering teams with duplicate alarms rather than synthesizing co-occurring symptoms into correlated incidents.
The Two-Tier Solution Principle
Raw telemetry, stack traces, and credentials must stay inside the customer boundary by default. The Central SaaS platform operates in a strictly metadata-only mode, ingesting only sanitized, allow-listed metrics and pseudonymous identifiers.

3. Local Data Protection: Field Allow-List & Redaction (Evidence 2)

The Local Collector implements a zero-trust allow-list policy configured in data_policy.json. Unapproved fields are dropped prior to network serialization:

Field Name Data Type Disposition Reason & Description
payload_id UUID v4 ALLOW-LISTED Cryptographic token ensuring idempotent deduplication during retries.
timestamp_utc ISO 8601 ALLOW-LISTED Global UTC timestamp for out-of-order handling and global time synchronization.
pseudonym_source_id String ALLOW-LISTED Masked host ID (e.g. srv-node-db01 replaces prod-db.internal).
metrics.* Float / Int ALLOW-LISTED Numeric indicators: CPU %, Latency ms, Packet Loss %, Auth Failure Count.
raw_log / payload String / JSON BLOCKED LOCAL Retained strictly in local SQLite. Never leaves customer environment.
credentials / keys Secret Token SCRUBBED / DROPPED Passwords, AWS keys, and bearer tokens redacted via regex scrubber.
customer_pii Identity STRICTLY DROPPED Names, emails, and identifiers stripped at ingestion before transmission.

4. The Four High-Value Observability Use Cases

1. Infrastructure Health

Continuous tracking of CPU saturation, memory utilization, and disk exhaustion with dynamic baseline modeling.

2. Network Performance

Round-trip transit latency (ms) and packet loss (%) with threshold breaching and BGP route deviation detection.

3. Authentication Security

Burst detection of repeated failed logins (brute force) producing security risk indicators without exporting usernames.

4. Collector Fleet Health

Real-time collector heartbeat tracking (<60s offline SLA), version telemetry, and SQLite buffer backlog monitoring.
